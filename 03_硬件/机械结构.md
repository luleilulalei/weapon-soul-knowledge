# 机械结构

当前已有机械V0.2原生Blender模型、12个STL及独立数字复核。该包用于不通电试片与空间假件试装，尚未验证承载挥动的成品。来源：[机械打印边界](<../90_来源/文档快照/S083_00_先读_打印边界与文件入口.txt>)、[机械复核](<../90_来源/文档快照/S086_独立机械复核_最终.md>)。

## 现有模型

主体190×60×49mm，整体约206.5×60×49.5mm。这是工程模型尺寸，不是已冻结的量产尺寸或舒适性目标。12个STL包含9个结构件和3个试片；先打印P08孔配合，再P09/P10滑配，拿实物零件核对后再打印整壳。

正面屏幕与附近麦克风、背面NFC、侧面扬声器；握持区域放电池、触觉器件并优先考虑IMU。核心交互区嵌入握持主体，单手重心与握持感优先。P06仅封概念顶口，不包含可承载挥动的通用配件连接器与机械锁止。

## 与当前工程的差异

| 机械V0.2依赖 | 当前变化 | 后续动作 |
|---|---|---|
| 旧10针FPC裸屏与旧座 | 用户已有GC9A01，12针FPC座 | 核屏幕包络、接触面、弯折与开窗 |
| LD0832BC-0195F LRA | LD0825BC-0169F | 更新固定、尾线、震感及干涉模型 |
| 旧NFC占位与天线方案 | 外接PN532/Grove候选模块 | 模块到货后验证背部空间、金属影响、线束 |
| 旧PCB布局与172条BOM说明 | V0.7.2 137位号，主控在上端背面 | 导入新板、核高度、天线净空和螺柱 |
| 概念顶口 | J7已明确六针电气接口 | 仍需机械锁止、插拔与受力设计 |

数字几何检查不能代替真实排线、声音、触摸、温升、重心和跌落验证。现行选型来源：[V072交付](<../90_来源/文档快照/S017_交付说明.txt>)、[配件接口](<../90_来源/文档快照/S015_配件接口定义_20261020.txt>)。
