# 绒芽与砺光

当前角色方向来自用户2026-10-20的明确选择：绒芽按成熟御姐、知心大姐姐；砺光按Jack式豪爽、重义气、想闯出名堂的性格，并保留大叔阅历。完整创作稿为[角色设定](<../90_来源/文档快照/S092_器灵角色设定_绒芽与砺光_V1.0.md>)；确认过程见[历史聊天摘录](<../90_来源/聊天摘录/01a159e1-6173-77b1-a9b5-711328ce0778.md>)。

## 共同基础

两人遇到玩家前就有自己的经历、偏好和愿望。核心人格由创作者定义；玩家可以命名和形成相处习惯，不能任意重写身份与价值观。双方可以不同意、争执、认错和互相照顾。

共同使命按2026-10-24新故事方向具体化：与玩家处理狂暴器灵事件，了解它们与主人共同经历的悲惨往事，并帮助解开心结。玩家以雇佣兵/特工式角色参与，身份和组织未定。两款目标一致，差异在处理问题的方式；相识和首季故事需要重写。来源：[RPG与故事方向确认](<../90_来源/文档快照/S115_协作RPG副手控制与狂暴器灵故事方向_20261024.txt>)。

## 人格对照

| 维度 | 绒芽 法棒 | 砺光 光剑 |
|---|---|---|
| 气质 | 成熟、敏锐、从容、有主见 | 豪爽、重义气、热情、有生活阅历 |
| 关注点 | 谁没被听见，选择会影响谁 | 眼前能做什么，风险和责任谁来承担 |
| 愿望 | 具体的人在困境中被认真对待 | 做成值得被记住的事，与搭档闯出名堂 |
| 缺点 | 隐藏自己需要、过信判断、拖延冲突 | 被激将、答应太快、隐瞒困难、爱面子 |
| 成长 | 更直接表达自己，也允许被照顾 | 把风险讲清楚，让搭档参与决定 |
| 深层信任 | 愿意讲自己的事，认真征求玩家意见 | 敢把后背交给玩家，承认没把握 |
| 表达 | 自然、温润、有分寸地调侃 | 直接、爽朗、具体，有安静和脆弱时刻 |

名字与核心人格继续按创作稿；地区背景、相识经历和任务对白需与新版故事核对，对话感觉的验证标准保留。Jack是性格参考，不把参考角色的身份、台词和故事直接复制成器灵。

## 对话必须保持的感觉

用户明确不希望角色像儿童玩具或统一措辞的AI客服。普通交流可以简短，不把每句都转成建议、安慰、总结和追问。观点被改变要有原因，情绪与关系要连续，不假装知道不存在的经历或未获准保存的记忆。

亲近不会让角色失去主见；不以玩家服从、每日登录、嫉妒或内疚推动关系。绒芽不总在教育和照料，砺光不总在兴奋鼓劲。通过连续闲聊、误解、反驳、沉默、共同任务验证角色，而非只挑几句好看的台词。

## 旧设定的处理

此前绒芽ENFP、砺光ISTJ只是助手建议，且后续气质已明显调整；最终V1.0没有冻结MBTI，不恢复旧标签。V1.5中“年轻好奇引路者”“克制任务型巡护者”的角色侧描述，以本次成熟角色方向替代。魔法丛林与赛博都市融合的既有视觉方向保留，具体地域与新版狂暴器灵故事重新衔接；旧《失声之城》不再作为当前主线。
