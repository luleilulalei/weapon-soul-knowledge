# 旧条款替代清单

本清单配合《器灵_非触摸显示屏_补充修订》R2（V1.4）使用。主修订优先于旧主PRD、横屏补充与扩展包中的冲突描述；不冲突的既有能力和安全约束继续有效。旧资产不覆盖，用新包中相同ID的修订显示稿替代。ID是追踪标识，不是必经操作步骤。

## 条款替代入口

| 旧条款与副本 | 废止 | 保留及新依据 |
|---|---|---|
| UIR-030（横屏总补充、模块01） | 菜单候选A/B、长按进菜单、短按循环、再长按确认、菜单超时；既定短/双/长按映射不再作为当前默认 | 实体非语音采音职责、唤醒/隐私分离、一次操作一个结果；主修订F03/F06/F07 |
| K03（改版决策、模块11） | 单键菜单作为可落地推荐的叙述，按键数量与默认按法假设 | 实体映射、误触、隐私持久化、远距停局、安全关断待决；主修订1.2/6.3 |
| device/screens.md 第7节 | 候选A/B状态矩阵中的菜单控制和默认手势 | 独立触摸、真实采音、过期输入不跨状态继承；主修订F01—F03/F07 |
| 扩展 device/spec.md 第2—4、6节 | 菜单机制及相应菜单验收 | 请求≠结果、隐私≠权限、安全关断≠黑屏；主修订F03/F07、R-T06/07/10 |
| 扩展承接第5节与EXT-T07/08 | 进入/循环/确认/退出菜单作为操作路径 | 分别替换为R-T06/07采音验收、R-T10电源验收 |
| HW-010及其总PRD/视觉描述 | 将“触摸”读作触摸显示面，或因此删掉全部触摸 | 屏幕周边及握持区均保留独立触摸；主修订F02 |
| UIR-057、游戏模块09及原型追踪12、联动稿第3节 | “触屏”对象不明确 | 明确“手机App触屏暂停”，远距停局仍未关闭；主修订F06 |
| D21—D24/M01 | 用于闯关记忆保留/舍弃或覆盖既有记忆 | 仅限硬件对话新记忆的许可与保存反馈；主修订F04 |
| D25/M02 | 原更正确认与“已修改”反馈 | 替换为查阅定位与只读查阅；既有记忆不可修改，主修订F04 |
| D26—D28/M03 | 屏内选择/确认/取消的视觉暗示 | 保留删除对象、影响、独立确认和真实结果；语音或App承接，主修订F04 |
| App按钮/列表/返回/输入法规范 | 自动套用于设备圆屏 | 手机App原能力保留；主修订F10/5.1 |

## X-D逐项替代

| ID | 旧含义 | 本次处理与有效依据 |
|---|---|---|
| X-D01 | 进入菜单、默认返回 | 废止菜单入口和返回焦点；仅表达当前等待状态，按F03/F07确定来源 |
| X-D02 | 选中关闭麦克风 | 废止选中状态；仅在真实关闭意图存在时表达请求状态，按F03 |
| X-D03 | 选中开启采音 | 废止可选开启项；仅表达真实等待/核对状态，不授予权限，按F03 |
| X-D04 | 选中深眠 | 废止睡眠选项；只表达真实待确认或入眠阶段，不把待确认视作已深眠，按F07 |
| X-D05 | 选中关机 | 废止关机选项；真实请求未发生不显示关机进行中，按F07 |
| X-D06 | 先松开这次按压 | 废止“释放后再次长按”的固定指令；不以旧稿冻结按法。保留消歧、一次输入一个结果，按F07 |
| X-D07 | 再次独立长按确认 | 废止屏内确认进度和固定第二次长按；保留明确非语音操作、权限和结果分离，按F03 |
| X-D08 | 菜单取消或超时退出 | 废止菜单返回路径；保留未提交取消无副作用、已提交须核对结果，按5.2 |
| X-D09 | 关闭请求待确认 | 保留事实语义，删除菜单来源依赖；未证实全部停采不显示已关闭，按F03 |
| X-D10 | 真实停采已确认 | 保留，关闭标记持续；普通触摸/唤醒不恢复，按F02/F03 |
| X-D11 | 开启请求待确认 | 保留，但必须先有获批非语音输入和有效权限；未知不提示可唤醒，按F03 |
| X-D12 | 真实开启已确认 | 保留，真实成功后才表现可采音，不恢复旧请求，按F03 |
| X-D13 | 深眠完成 | 保留事实；显示仅为能力允许时的阶段样张，不承诺深眠持续点亮，按F07 |
| X-D14 | 正在关机 | 保留，必须由真实关机过程触发，不将意图或菜单选择当过程，按F07 |
| X-D15 | 安全关断未确认 | 保留，明确先别拆装；黑屏和动画都不是安全证据，按F07/F11 |
| X-D16 | 真实安全关断后的完成 | 严格有条件保留；仅真实安全信号与剩余反馈能力均成立时短暂显示，随后熄屏。无显示能力则用获批替代渠道，按F07/F08 |

新画面不得把X-D01—08按顺序连成另一套隐形菜单。所有帧只表达有效输入与真实设备事实；正式输入映射仍须批准及实测。

## V1.4 新增边界

- 既有记忆仅查看、删除，所有编辑、改写与覆盖保存流程废止。
- 闯关无记忆保留询问、保留/舍弃选择或开关；不据此决定自动存储策略。
- 器灵对话仅在硬件侧；游戏 App 无器灵对话入口、输入或发送链路。
