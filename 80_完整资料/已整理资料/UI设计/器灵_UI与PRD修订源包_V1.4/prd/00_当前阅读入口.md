# 器灵 PRD V1.4｜记忆管理与对话端分工修订

本目录是2026-10-18用户最新要求的专项变更集，不是完整13模块重新定版，也不是软件已实现证明。

先读《01_记忆与对话端分工_决策补充.md》，再按《02_旧条款替代矩阵.csv》定位受影响旧文，最后执行《03_验收用例.md》。V1.3完整模块与非触摸R1中不冲突的要求继续有效；本次三项决定优先于相冲突的旧条款、页面、模拟流程和测试脚本。

本次已确认：
1. 已保存记忆允许查看、删除，不允许修改。
2. 闯关结果不提供“是否保留记忆”操作。
3. 游戏/App端不支持器灵对话；只有实体硬件端能对话。

未确认：自动长期记忆的触发、许可范围、保存类别、期限与关系成长规则。本次移除操作不等于批准自动保存所有关卡或所有对话。

本次不更改单IMU硬件方案，不因讨论双IMU增加传感器，不改变账号权限、删除确认、充电完整AI陪伴、非触摸圆屏等既有要求。
