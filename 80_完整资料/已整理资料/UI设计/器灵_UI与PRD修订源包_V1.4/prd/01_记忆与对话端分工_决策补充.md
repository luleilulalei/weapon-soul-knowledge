# 器灵｜记忆管理与对话端分工决策补充

版本：PRD V1.4专项修订｜2026-10-18

## 1. 裁决、范围与优先级

用户最新明确要求：“记忆允许查看删除不允许修改；闯关记忆不需要是否保留记忆操作；游戏端不支持对话，只有硬件能对话。”本修订将软件端统一按App/游戏处理：不得保留或新增器灵聊天输入入口，硬件状态查看和配置仍可由App承担。

本文件覆盖旧文中相冲突的功能、按钮、状态、链接、验收和实现任务。旧来源全文仅作追溯，不能从旧截图、菜单或某模块副本恢复已废止能力。编号V14-*是本次变更编号，不伪造旧Q号；未发生冲突的已确认功能与安全边界继续有效。所有验收目前待执行。

## 2. V14-M01｜已保存记忆只读与删除

状态：已确认；P0。替代AI-012的“更正”能力和UIR-034全文。

- 前置：当前账号拥有对明确器灵及目标记忆的有效访问资格。
- 入口：App记忆列表进入只读详情；展示真实摘要、来源、日期与保存/清理状态。可返回、查看状态及发起删除，不出现编辑、纠正、改写、保存修改、撤销修改或编辑历史入口。
- 用户不得修改已保存记忆的正文、摘要、来源、时间或所属对象。实体语音“把这条改成……”同样不执行修改；说明现有记忆只能查看或删除。不得用“删除后自动新建”“后台纠错”或新增一条替代记忆绕过该限制。
- 记忆修改界面、业务动作及面向用户的修改API/命令不进入实现范围；已有原型编辑链接、路由或直接调用必须被移除或拒绝，不仅隐藏按钮。技术接口形式另由实现设计，本稿不编造具体URL/API。
- 删除处理中、删除失败、同步状态等系统元数据变化不是用户修改记忆正文；仍按真实删除流程呈现。
- 账号昵称、设备名称、联网配置等独立设置不因此一并禁止。但不能在记忆详情伪装成“称呼偏好设置”继续改写记忆；若某字段同时影响设备设置和已存记忆，应先分清对象，不静默双写。
- 本条禁止用户改写操作及借后台动作绕过该限制，不一概禁止系统内部记忆形成或整理；具体自动策略须单独明确，不能从本次要求推导。
- 对未来从新硬件对话形成新记忆、冲突内容如何处理，本次未规定自动覆盖/合并策略；不能因旧内容被指出错误而默认为获准修改。

## 3. V14-M02｜删除权限、确认与结果保持

状态：查看/删除已确认；原有删除传播、保留与可恢复政策仍按K02/D06/D10待决项处理；P0。

- 发起删除前核对本人资格、器灵和目标记录；确认页说明所选内容、影响范围、是否不可恢复及真实支持的后果。不猜测恢复期限。
- 硬件端可承接获准语音删除流程；目标模糊先澄清，身份不明不读出私人候选。App仍可用正常按钮执行记忆管理，但不因此成为聊天端。
- 确认前取消不改变数据；提交后显示处理中、待核对、部分完成、失败或完成。离开页面不是撤销已提交删除，重试核对原目标，不产生额外删除。
- 设备离线或副本未清理时不宣称全部删除；恢复连接不得把已删除私人内容从旧缓存重新写回或从战绩重建。停用引用和传播时序须对应已获批政策与真实能力。
- 删除记忆、关闭未来记忆保存、关闭采音、退出账号、解绑、删除账号是不同操作。保持各自权限与确认；不能删记忆顺带撤销合法战斗成长、技能、卡牌权益。

## 4. V14-G01｜闯关结果不做记忆保留选择

状态：已确认；P0。替代UIR-032在关卡结果场景的操作、UIR-061的记忆许可卡和UIR-064的结果记忆交互。

- 正常成功、失败、重复通关、退出、中止、结果待核对及重开结果页，都不提供“记住这段经历/暂不记住”“保留/不保留”“允许记住”等弹窗、卡片、按钮或必经分支。
- 主流程为真实结果、实际奖励/解锁及下一步：继续、重试、教学、休息或核对。离开结果页、下一局和战斗权益均不得依赖记忆回答。
- 不把旧弹窗移到首页、成长页或稍后通知，继续追问同一局的保留选择；不以无按钮的自动同意代替原操作。
- 不在结算页伪造“已记住”、默认注入关卡摘要或关系成长。必要战绩/结算事实与AI长期记忆分开：移除记忆操作不删除真实战绩，也不新增保存原始录音、轨迹或完整聊天的权限。
- 记忆列表仍可查看已经真实存在且有权访问的记录，包括原先合法保存的游戏来源记忆，并按V14-M02删除；不得因来源为关卡就批量删除既有记忆。
- 自动形成长期游戏记忆、是否可被硬件回顾及关系成长的触发仍待V14-P01明确。待定期间不在原型中展示为已实现自动留存；只按可证明的已获批范围处理已有记录。

## 5. V14-C01｜器灵对话仅在实体硬件端

状态：已确认；P0。替代APP-007中的软件“完整对话入口”，并约束所有App、游戏及首用界面。

- App/游戏不提供器灵文本聊天框、发送按钮、按住说话、语音聊天、手机麦克风录入对话、对话会话页或文字/语音转发到器灵的替代入口。
- 手机端可显示设备在线/离线、真实采音、联网服务、当前状态和必要操作说明，可管理设备、账号、权限、记忆查看删除及既有配置。状态字段不变成可输入聊天的窗口。
- 首用问候可以提示“对实体器灵说话”并显示硬件真实状态；取消软件端“点一下发起问候/代发一句话”的模拟产品入口。独立联网硬件对话不要求手机App常驻。
- 完整对话的麦克风输入与器灵语音输出在硬件端完成；App不承担对话播放/播报代理。游戏既有音效、教学提示、非交互器灵鼓励文案、按钮、暂停、结果说明和设备命令不因本条全部取消，但不得包装为与器灵聊天。
- 战斗中完整对话与已有有限硬件指令的分离继续有效；本条不擅自取消已确认的实体本地指令，也不新增手机语音指令入口。
- 对话涉及私人记忆时仍需主人权限和合法可引用范围；关闭采音、离线、失败与未知状态均据真实硬件能力反馈，不能由App伪造成功。

## 6. V14-P01｜尚未决定的长期记忆规则

仍待产品决定：哪些游戏事件可进入长期记忆、是否自动形成、对应许可范围和入口、保留期限、引用与删除传播规则、重复/冲突记录、关系成长条件。

此次删除“每局是否保留”不等于同意“所有局自动记住”，也不等于永久禁止保存任何游戏来源记忆。不得将旧K02“逐条同意”的推荐重新带回闯关流程；其他场景也不得借本次修订新加许可流程。保留已批准权限与设置，不把尚未批准的开关画成可用功能。

## 7. 跨模块承接与验收门槛

- 00总PRD、03 AI、05养成：统一“硬件对话；记忆只读/删除；自动留存未定”，移除将记忆编辑或结算许可当闭环必需步骤的描述。
- 07 App、09游戏：移除软件聊天与结果保留选择，保留真实结果及权益一致性。手机键盘仍供登录、命名、联网等真实表单使用，不能因删记忆编辑而全局删除输入规范。
- 08账号：保留读/删资格、账号生命周期和隐私配置；记忆“删改”中的改写能力废止。
- 01硬件、02视觉、非触摸R1：硬件对话与只显示圆屏保持；R1 F04中记忆“更正”及D25更正语义废止，不能改成屏内按钮。
- 10验收、11决策、12追踪：新验收替代旧“只更正一条”与“结算同意/拒绝记忆”脚本；K02/D10未因此全关闭。
- 04动作与IMU：维持当前单IMU边界，本次不改传感器数量、算法或硬件电路。

交付程度：本目录完成需求与替代关系定义。UI资产按同批修订另行交付；未实现软件、未执行端到端测试，不宣称旧路由或真实服务已经删除。
