# Spirit v0.1：先编译，再上板验证

这是在你提供的 Usaki 工程上直接改出的第一版，不是重写语音协议，也不是宣称已经实机验证的量产固件。

## 已接上的主路径

- 单个 GC9A01 屏幕；保留原眼睛动画。
- 单个 PDM 麦克风：GPIO4 DATA、GPIO5 CLK，I2S0 接收。
- MAX98357A：GPIO7/15/16，GPIO17 使能，I2S1 播放；共享升压按使用者管理。
- 原有 Opus、设备注册、语音 WebSocket、服务端情绪/眼睛指令继续复用。
- 旧双麦、MPR121、PCA9685、耳朵/手臂/身体舵机从实际编译与启动中移除。
- BMI270 使用 Bosch 官方驱动和配置数据；CAP1296 六路触摸；TCA9534 底座/充电状态；电池 ADC。
- 单独 Spirit 遥测/效果通道。未知的光剑协议明确拒绝，不伪造“执行成功”。

## 第一次上电的交互

默认**软件静音**。KEY14 长按 1.5 秒切换静音，保存到 NVS；短按开始一轮说话，再短按结束并交给服务端。播放期间短按是打断播放，不同时开麦。屏幕显示 MIC MUTED / MIC READY / LISTENING。

静音只停止采音、唤醒与上传，**不是物理断麦**。重连、触摸、模式变化和服务端回复不能绕过静音。NVS 损坏不会自动擦除；存储写失败时本次运行保持静音，并必须处理错误后才能承诺重启持久性。

## 本地构建

使用 ESP-IDF **v5.5.1**，目标 `esp32s3`。版本与完整核验见 `README_SPIRIT.md`。

```sh
. /你的路径/esp-idf/export.sh
idf.py set-target esp32s3
idf.py menuconfig
idf.py build
```

在 `Spirit v0.1 configuration` 中填 Wi-Fi、唯一设备 ID、设备连接 HTTP URL、语音 WebSocket URL、Spirit 遥测 WebSocket URL。默认没有真实账号/密码/地址，不会连接原作者服务。开发环境使用隔离局域网；生产环境还缺少完整鉴权/配网/密钥管理。**不要把云服务 API Key 烧进设备。**

## 尚不能直接承诺

- 未烧录、未实机测试；编译通过不等于电气/音频/实时性能验证通过。
- 马达默认关闭。型号、额定电压和台架校准须按外设目录说明确认；远程 `haptic` 在未配置时返回拒绝。
- J7 共用电源，必须断电插拔；检测不等于热插拔保护。剑身命令格式尚未提供。
- PN532 是可选驱动，默认不初始化；UID 不是安全身份凭证。
- 电池毫伏不是准确百分比；IMU 原始六轴读数不是真实空间轨迹。
- BLE/Unity、OTA、完整省电策略、量产认证、完整 AFE/唤醒模型调参尚未完成。

外设细节：`src/spirit_peripherals/README.md`。源码保留的旧 Usaki 文件只用于追溯，不代表它们仍在 Spirit 上运行。
