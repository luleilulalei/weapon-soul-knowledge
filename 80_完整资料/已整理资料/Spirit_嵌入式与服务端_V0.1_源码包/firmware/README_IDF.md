# Usaki ESP-IDF Native Build

This branch is built with native ESP-IDF, not PlatformIO.

## Environment

Expected ESP-IDF path:

```powershell
D:\espidf\esp-idf
```

Use ESP-IDF 5.5.x for the ESP-ADF audio migration path.

## Build

Open a `cmd.exe` shell and run:

```cmd
D:\espidf\esp-idf\export.bat
cd /d D:\code\usaki\usaki
idf.py set-target esp32s3
idf.py build
```

Or open PowerShell and dot-source the export script:

```powershell
. D:\espidf\esp-idf\export.ps1
cd D:\code\usaki\usaki
idf.py set-target esp32s3
idf.py build
```

Do not double-click `export.bat`, and do not run `export.ps1` with `-File`, because the environment changes will be lost when the child shell exits.

## Flash And Monitor

```cmd
idf.py -p COM3 flash monitor
```

Replace `COM3` with the active device port.

## Notes

- `sdkconfig.defaults` pins ESP32-S3, 16 MB flash, custom partition table, and OPI PSRAM defaults.
- Component dependencies are declared in `src/idf_component.yml`.
- `managed_components/`, `dependencies.lock`, and `sdkconfig` are generated by ESP-IDF and ignored by git.
