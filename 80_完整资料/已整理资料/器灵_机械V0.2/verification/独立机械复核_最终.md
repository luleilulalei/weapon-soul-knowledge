# 器灵机械V0.2独立复核

复核日期：2026-10-17。结论适用于audited_source_hashes.json和stl_geometry.json记录的冻结文件。

## 结论

本轮数字几何通过，可进入不通电的试片、尺寸假件和空间样机打印；不等于实际零件已装配验证或带电运行批准。

- 12个当前STL全部为一个闭合连通实体，非流形边0、定向边错误0、零面积三角形0，体积为正。
- Blender实际单位为METRIC、Scale Length≈0.001、MILLIMETERS；STL坐标已经是毫米，切片时不要再乘1000。
- 打印件两两、器件包络与打印件、器件包络两两均未检出超过0.001 mm³的正体积穿透。
- 屏幕排线路径、连接器布局/锁扣工具、扬声器后腔、NTC、LRA焊接与出线及电池引线服务空间，不再侵入不相关实体。自身包络包含和共用线束路径仍会在交集清单出现，不能误读为零交集。
- 电池与附着NTC从已拆下的后盖/托架沿+Z抬起32 mm，每0.5 mm采样均无实体穿透。绑带解除、插头断开、手指和柔性线束没有做运动仿真。

没有宣称真实PCB已布下、天线已通过、FPC弯曲已获批准、声腔已调谐，或电池可在打印壳内充电。

尾长47.5±0.5 mm自屏下缘起，10pin、0.5 mm节距，端宽5.5±0.1 mm、端部接触长5±0.5 mm、插接厚0.3±0.05 mm；平直状态接触面朝显示正面、PI补强在背面。模型FPC宽5.6、厚0.35，体积反推中心线离散长度约47.492 mm，吻合47.5 mm名义路径。

R6.7的180°回弯只是工程候选，不能称厂家最小安全弯曲半径。首10 mm不弯区、芯片高度盒和整段恒厚均为保守/未定假设；图上芯片区及允许弯区没有完整尺寸。必须取得实物/厂商弯折规则，不能按渲染强折。

回弯后的接触面朝后，末端接座布局约Y126.05、Z3.2附近。Omron XF2M-1015-1A仍以布局盒及锁扣工具空间表达，不是假装已有准确连接器STEP。13×9×4 mm布局盒有空间不代表焊盘、触点、锁扣方向和插入深度已验证。

新增硬性PCB约束：顶部X±8、Y100..135共16×35 mm必须保留到板面Z1.6的无其他器件区，供排线、接座和锁扣动作。另保留26×26 mm扬声器后腔区域，上件高度仅约0.2 mm。34×105 mm主板是未布线预算，两个禁布区明显减少可用布局面积；必须重新布局/DRC后导出真实STEP再判定整机尺寸。

### 电池、NTC及保持方式

Keeppower 1S1P18650-400T官方最大包体Ø19.1×69.2 mm，模型使用该最大值；22×72 mm只是设计安装预算。[厂家规格](https://www.keeppower.com/product/protected-1s1p-li-ion-ncm18650-3-6v-3850mah-13-86wh-with-temp-protection/)

托槽内径20.3 mm，对最大电池径向间隙0.6 mm；端止挡内面约Y60.25/131.75，电池端Y61.4/130.6，每端约1.15 mm。两条软绑带槽用于保持，软扎线锚点仅用于工厂引线应变释放，不可勒紧包体或拉扯电池引线。保留外部绝缘NTC侧腔及引线槽，NTC热耦合胶/绝缘层和温度响应未验证。

托架螺钉中心X±18、Y76/110，位于电芯与NTC外侧。常规M2.5头/螺母投影与电芯分离；实际头型、螺母方向、突出长度和垫片未建模为全部金属实体，必须按清单与实物量验，严禁尖端指向电芯或剥开保护包装。

### LRA及引出尾

已独立查看LD0832BC-0195F厂家PDF第13页：Ø8±0.1、厚3.25±0.1 mm；本体按Ø8.1×3.35建模。顶部0.3 mm泡棉与底部0.15 mm胶另列为名义层厚，不能把本体最大加名义胶厚称为厂家整体最大尺寸。图框的一般公差和层厚公差应向供应商确认。

短FPC从圆心到尾端10.4±0.2 mm，模型按最大10.6长度；尾宽4.2未单注公差，图框通用公差分配也需厂家确认；模型取4.7 mm工程保守包络，绝不是厂家最大值。UV根部高度上限2.5 mm，焊点和柔性引线另有审查区。尾部有托台与独立应变释放，不能在UV根部硬折或用拉线保持马达。

可拆上限位固定在打印支柱上，顶部中央让空，理论上不靠螺钉压紧马达。名义泡棉顶至限位底约0.5 mm；若泡棉与胶各增加0.2 mm，剩余仅约0.1 mm，需量验。数字无碰撞不验证振动传递、松脱、噪声、驱动波形或耐久。

## 试打印顺序

1. 先P08螺孔/螺母试片，P09/P10板厚槽与单边0.3 mm滑配量规。测量打印收缩、实孔和真实五金，不直接相信名义间隙。
2. 再P04托架、P05屏框、P11/P12 LRA座与限位，用不带电尺寸假件检查支撑、软垫、线尾、取出和螺丝突出。
3. 最后打印前后壳。STL已按建议方向置于构建板，前壳分型面朝下、后壳外侧朝下/腔朝上；前壳内部顶板、1.0 mm FPC屋顶、台阶和螺母槽需切片预览并确认可拆支撑。没有切片器/打印机测试证明。
4. 实物安装前核对厂家版本、屏FPC弯区、连接器插入/解锁方向、胶层/泡棉和电池工厂出线。先断电、断开电池、解开保持带再拆装；不将本包用于封闭壳体充电或挥舞/冲击测试。
