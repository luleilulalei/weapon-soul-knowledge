# 器灵首发产品总纲 V1.5 设计提案

日期：2026年10月18日。适用对象：产品、剧情、角色、美术、游戏、硬件与测试。

首发体验围绕两件事组织：与一位有持续身份的器灵建立情感关系；通过实体动作，与它一起完成有剧情、有怪物、有战利品和Boss的冒险。主线提案为《失声之城》：玩家从魔法丛林走入赛博都市，寻找两地共同失去的回应能力。

## 1 当前决定与提案范围

用户本轮明确方向：首发预计两款器灵，分别为法棒与光剑；法棒通过空中绘图施放攻击和防御魔法；世界内容融合魔法丛林与赛博都市；情感培养和体感游戏为双核心；首发体感内容采用剧情关卡，包含怪物、战利品与Boss。

本包据此按两款产品并行设计。两款的最终商业发售组合仍依用户所说的“预计”，不能据此承诺量产或发售时间。世界名称、角色名字、12关规模、技能数值、奖励、关系阶段和记忆自动策略均为本次完整设计提案；可用于原型制作和评审，尚不是已批准量产需求。

既有确认继续有效：实体才是对话端；软件端无聊天；已存记忆只读和删除；结算不询问是否保存记忆；每台实体独立身份；一位玩家当前使用一把器灵；首版无双实体互动；Android优先；圆屏仅显示；充电禁体感战斗；入座结束当前游戏；离线本地训练不产生长期成长。

“两款可买”不等于“两款同时参战”。首发建议任意单款可通关全部12关、获得完整结局，不要求购买另一款解谜、打Boss或补全结局。

## 3 用户完整循环

拿起实体→器灵短回应→App选剧情关→设备和场地准备→关前剧情→体感对战→关内安全休息点→Boss或末波→确定结算→获得战利品和剧情进展→离开战斗→与实体回顾或闲聊→下次拿起时感到它记得相处方式。

战斗结算与聊天彼此独立。玩家不聊天、不保存私人记忆也能完成全部剧情、正常获得战利品。剧情本身的固定角色台词由游戏内容系统呈现，不借手机提供开放式AI对话。

## 4 首发内容预算提案

| 项目 | 首发建议 | 明确边界 |
|---|---|---|
| 产品 | 法棒、光剑各一款 | 不共享同一角色身份，不承诺共用PCB |
| 游戏 | 单人固定站位剧情体感 | 无房间移动、真实空间命中、多人联机 |
| 场景 | 森林、都市、交界核心3套主题 | 用固定机位战斗点和路径镜头复用，不做开放世界 |
| 关卡 | 3章×4关，共12关 | 每章第4关Boss；教学融入第1关 |
| 怪物 | 6个普通行为原型、2个精英变体 | 外观变体不额外计算成新行为原型 |
| Boss | 3个，分别2、2、3阶段 | 每阶段教授过的动作组合，不突然增加新手势 |
| 技能 | 每款4个主动技能 | 光剑3攻击1防御；法棒3攻击1防御 |
| 陪伴 | 2个人格、4关系阶段、10类日常事件 | 无每日好感签到与不登录惩罚 |
| 战利品 | 12件固定纪念物、基础材料、3个Boss外观 | 无随机装备词条与付费战力门槛 |

关卡目标体验：普通关约4至7分钟、Boss关约6至9分钟，包括短剧情与休息点。12关一次成功路径约54至90分钟，教学、失败重试和陪伴另计。这是内容预算，不是已测通关时长或“数小时首发剧情”的宣传承诺。

## 5 首发价值与边界

法棒的独特价值是“我亲手写出魔法”；光剑的独特价值是“我与伙伴一起读懂攻防并完成反击”。共同价值是同一段冒险会改变器灵与你交谈的细节。

不通过堆叠刷怪时长扩大体量。成长主要提供新动作、新解释和新表达，基础属性提升有限。关卡不要求对空气猛烈击打、不要求撞击家具或另一把器灵，不把大力与高伤害挂钩。

首发是否商业可行仍需核算两套实体、语音服务、剧情资产及售后成本。本包确定功能与内容结构，不虚构售价、销量或研发工期。
