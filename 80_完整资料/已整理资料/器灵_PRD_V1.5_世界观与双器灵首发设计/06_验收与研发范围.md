# 验收 版本承接与研发范围

## 1 本轮范围变化

| 项目 | 旧基线 | 本轮承接 |
|---|---|---|
| 实体产品 | 主要设计光剑 | 按预计双款首发增加法棒产品线；最终发售组合待定 |
| 游戏结构 | 训练场、教学、三项挑战 | 用户要求改为剧情关卡、怪物、战利品和Boss；本包提出12关 |
| 世界内容 | 人格与背景未完整定义 | 提出同一灵流文明的森林/都市及三章主线 |
| 输入 | 光剑方向、姿态、时机 | 继续保留，法棒新增真实空中绘符，独立验证 |
| 技能解锁 | 节拍/回锋/蓄势旧演示顺序 | N02解锁组合/三角，N06解锁蓄力；仅本提案范围生效 |
| 情感 | 固定人格，阶段及自动记忆未定 | 两个人格、四阶段、相处标记和类别记忆方案待评审 |
| 对话端 | V1.4实体对话 | 保持；游戏固定剧情与提示不变成聊天端 |
| 记忆 | V1.4只读/删除，结算不问是否保留 | 保持；自动形成策略另列提案 |
| 双器灵互动 | 首版不做 | 保持；双SKU不等于双设备合作 |
| 离线训练 | 无长期成长 | 保持；不把新战利品变成离线补奖 |

本包作为V1.5设计提案追加，不覆盖旧来源、PCB、Unity实现或真实账号数据。旧文中不冲突的身份、权限、非触屏、安全、取消旧事件、奖励去重继续有效。涉及新数值/政策的实现采用提案配置和虚构数据，不宣称用户已逐项批准。

## 3 实机测量计划与候选发布目标

以下是新提出的评审目标，不能覆盖旧D09为已批准指标。目标过不了应先修改识别/窗口/动作语法并复测，不删除失败样本来达标。

输入识别：探索阶段每类每手至少30个有效示范用于找问题；发布候选评估另用未参与调参的至少20位成年体验者，各支持手别每类至少20次，按用户、手别、动作和硬件版本分别报告。此为可执行采样方案，不能直接宣称覆盖全部人群。

候选门槛：整体有效动作正确识别率至少95%，每一类动作在每种受支持手别下至少90%；两项同时满足，不能用总体平均掩盖某个图形或左手适配失败。同时报告漏识别、误分类、95%置信区间与人群差异，不把拒识算正确。

负例包含自然拿放、走动、触摸、姿态调整、半图和错误图。候选目标：明确无效输入误施法率低于1%，空闲负例观察中每30分钟不超过1次误动作候选且战斗外实际施法为0；这些指标分别测量，不能用“战斗外有门禁”掩盖算法误判。

端到端候选目标：有效动作完成到确认反馈P95不超过250毫秒；法棒整个绘符动作耗时另报，不计入250毫秒；云端AI首次有效语音P95不超过3秒，以用户说完到听到有内容回应计，提示音不算。按网络、设备和路线报告，达不到需给出真实等待与失败设计。

体验候选目标：完成一次教学后，至少80%测试者能在辅助难度独立通过N01；两路线同关首通成功率差异不超过15个百分点；单关主观疲劳0至10分中位数不超过3，出现疼痛立即停止，不把平均轻松当个体安全证明。采样用于产品调试，不能代替量产安全认证或儿童适用评估。

上述人数、成功率、延迟、疲劳阈值均需评审并实测；首发年龄范围仍待决定，当前先用成年测试者。法棒识别是产品放行门槛，不能仅用鼠标模拟通过战斗规则来代替。

## 5 建议研发阶段

阶段A，先验证法棒：用简单画面完成三种符形的真实输入、识别反馈、暂停和误触发测试；同时用现有光剑动作系统做同样的攻防裁决。输出识别报告与交互修订，不先购买大批新硬件。

阶段B，做一段完整可玩样片：以N01/N02教学缩编接N04 Boss，包含一套森林场景、两条输入路线、一个器灵硬件陪伴、真实唯一结算与虚构账号测试。缩编样片只用于验证，不等于完整首发关卡被取消。确认绘符好玩、光剑有攻防、角色有个性后再量产内容。

阶段C，完成第一章4关与两个人格：完成从第一次见面到Boss后回顾的闭环；验证奖励、记忆关闭与删除、换器灵隔离。没有云端权限与删除证据前仅用虚构测试数据。

阶段D，复用基础制作第二三章：每章新增主题与机制组合，按04完成N05至N12；覆盖两产品和两难度。先补机制与提示，后补精细美术与配音。

阶段E，首发候选：实机、连续运行、账号生命周期、服务成本、年龄范围、售后身份连续性与商用内容权利逐项关闭。两套产品同时首发会扩大装配、固件、动作识别和测试矩阵；不以“换外壳”估计工作量。

## 6 尚需产品确认的关键选择

1. 世界提案：同一灵流文明、静默协议危机、修复循环的结局，以及两款角色原型。
2. 首发体量：三章十二关、三个Boss；双款同发还是法棒通过实机门槛后再确定同步发售。
3. 成长经济：固定掉落、300首通灵屑、纯外观用途、独立器灵资产，不做刷数值装备。
4. 陪伴政策：四阶段相处标记、主动互动上限、类别记忆授权、100条容量和删除策略。
5. 发布目标：受支持的手别、年龄范围、法棒识别与舒适性门槛、网络资格和检查点恢复。

这些问题不阻断世界观、关卡原型和虚构数据评审；真实私人数据保存、量产和对外性能承诺必须采用明确通过的版本。
