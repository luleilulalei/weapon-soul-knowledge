# 器灵 V0.7.1：移除麦克风台架跳线，保留断电隔离

本包是可导入 KiCad 的原理图工程与工程审查稿。本版仅移除JP1台架跳线，将原MIC_FEED并入+3V3，直接供给Q1源极及R11上拉。Q1与U9/U10保留，其他电气不变。V0.7的LRA和十针FPC显示继续沿用。没有已布线 PCB/Gerber，也没有实物上电、打板或打印装配合格结论。

## 先打开哪些文件
- `Spirit_V0.7.1_review.pdf`：21 页原理图，本次重点看第8页麦克风供电及第21页ERC假设；第19页触觉保留；第12页FPC显示、第16页逻辑稳压和充电禁用约束保留。
- `project/Spirit.kicad_pro` / `project/Spirit.kicad_sch`：完整层级工程。符号库和候选封装库随包，不要仅导入一张子图。
- `output/Spirit_V0.7.1_KiCad_Import_Project.zip`：只含最新工程，便于嘉立创导入。
- `BOM_JLC_映射_V0.7.1.csv`：元件型号、立创编号、封装候选和采购/验证问题。
- `validation/`：本版网表逐脚检查、ERC 与独立复核。ERC Source Assumptions 页里的 PWR_FLAG 只是告诉电气检查器某网有电源来源，不是要购买的器件，也不是供电稳定保证。
- `source/baseline_v07/`：仅为可复现差异保留的V0.7旧版本基线，不要作为最新工程导入。

## 本次麦克风精简

- JP1已从原理图和BOM删除，不再购买或操作这只台架跳线，也没有新增短路帽。
- Q1源极及R11上拉直接接+3V3网（实际目标3.192V），Q1仍负责麦克风供电开关。
- U9保留PDM时钟断电隔离，U10保留PDM数据断电隔离；两者不是第二个麦克风。
- 关麦测试改为测Q1后级MIC_3V3电压与支路电流，并检查PDM信号反灌；不要再按拔JP1的旧流程测试。若需串入电流表，必须先断全部电源，按临时测量工装操作，不能带电断线。
- 软件异常、复位、卡死时是否真正关麦仍需故障注入验收，不能把按钮图标或ERC通过当作隐私保障。
- 未实施外接I2C附件的新改动。

## 沿用的V0.7触觉改动

1. M1改为LEADER **LD0832BC-0195F / C7472499**，真正Z轴LRA；J110仍只是它的两线接口。
2. U105改为**DRV2605LDGSR / C527464**，10脚VSSOP专用闭环驱动，从同一3.192V逻辑轨取电。删除TPS7093V供电、Q101低侧MOS、D101续流二极管、R127/R128、C116/C117/C118及J109。
3. GPIO6经1k串阻控制EN，100k下拉默认关闭；GPIO18恢复NC。触觉控制改用共享I2C地址0x5A。
4. 保留10µF输入储能C119，C120改1µF REG去耦，新增C121=1µF VDD去耦。

## 保留的FPC显示与电源设计
1. DS1 为 HOTHMI **TFT-H013A6QQIGC5N10** 无触摸裸屏，直接通过自身 10 针、0.5mm FPC 插入 J8。
2. J8 选 **Omron XF2M-1015-1A / C271735**，真正双面接触 FPC 座；随包提供按厂家图建立的10针候选封装。
3. 屏针序：1LEDA、2VCI、3CS、4RESX、5SCL、6SDA、7D/CX、8TE、9LEDK、10GND。TE 不使用，J8和DS1第8脚均明确NC。不得接旧12针屏，也不得按Waveshare八线接法连接。
4. 恢复 Q2/AO3400A 低侧背光PWM，R37=100Ω栅极串阻、R38=100k下拉。R39 为 **1206W4F680JT5E / C17976，68Ω±1%、250mW、1206**，本版必须装，不再是DNP。背光由+5V_SYS经R39供给，复位期间栅极硬件下拉灭灯。
5. R117 改 **RT0603BRD07432KL / C861402，432kΩ±0.1%**；R118 改 **RT0603BRD07100KL / C122538，100kΩ±0.1%**，两者25ppm/℃、100mW、0603。历史网名仍叫+3V3，**实际稳压目标为3.192V**，必须按目标测量而非认为目标是3.300V。

## 为什么逻辑电源降低一点
面板图纸VCI为3.2±0.2V，但厂家附带的旧GC9A01芯片资料工作上限为3.3V，因此按较严格3.3V设计。432k/100k名义输出0.6×(1+4.32)=3.192V。

以TI反馈表0.588–0.612V及两只电阻0.1%计算，静态范围约3.123–3.261V；若示例叠加每只电阻±25ppm/℃×100℃漂移，约3.110–3.274V。**反馈表默认25℃，上述不是全温、启动和纹波的保证**，TI也说明轻载省电模式输出可能略高，需实测整个系统。

已知固定负载供电范围覆盖此目标：ESP32-S3模组、CAP1296最低3.0V；BMI270、TCA9534、LVC1T45电平转换、LMD3526T261-OA5麦克风的电源范围也覆盖。未知NFC/UART外设仍须按实际型号核对，低电池压差仍是原系统未关闭项。

厂家宣称屏可兼容3.3V MCU、屏仅引出单VCI，但没有完整内部IOVCC接线图。当前使用同一逻辑电源驱动SPI是有依据的样机假设，仍须验证逻辑电平、启动和SPI信号，不能当作厂家完整内部设计签核。

## 背光和供电验收
- 5V、Vf3.0–3.4V时，68Ω电阻估算约23.5–29.4mA。
- 按5V系统最高5.5V、Vf最低3.0V、R最低67.32Ω，约37.14mA、92.84mW；250mW电阻仍需按环境温度降额。不是40mA恒流，也不保证500nit。
- 开灯前先让+5V_SYS建立，GPIO48初始低；关机先关PWM。保留33Ω SPI源端串阻，RESET上拉与去耦。
- 不带电插拔屏排线、换跳线或切接外供。先断全部电源，核对1LEDA/2VCI/10GND连续性及对地无短路，再限流上电。
- 暂不接屏先测逻辑轨，在实际屏端和MCU供电端用示波器验证 **3.0–3.3V**：启动、轻载、Wi-Fi峰值、显示变化、声音/马达并发、合法源切换、低电池和预期温度。超过范围时停止接屏并修订供电，不以万用表平均值通过。
- 再接屏测背光电流/温升、灰阶与彩条、复位恢复、SPI时序和掉电行为。逐步增负载，记录各电源波形和电流；禁止直接用整剑满亮做第一次测试。

## FPC装配必须注意
屏正面观察、排线朝下：10号在左、1号在右；触点面与显示面同侧。座子双面触点只解决接触面，不允许把1–10电气顺序反过来。封装PCB顶视焊脚行1号在左，最终必须结合排线弯折路线整体旋转座子并逐线确认。

Omron适用厚度0.30±0.05mm，匹配屏厚度。屏尾宽5.5±0.1mm，座推荐5.5±0.05mm，公差没有完全包络，**必须买样品试插、锁扣和连续性检查**；不要裁切FPC当成已解决。候选封装两块无编号焊片仅机械固定，不虚构接地脚。闭合约2.1mm、开锁约3.1mm；壳体还须预留手指/工具开锁与排线弯折空间。没有最终排线走向或全公差装配签核。

## LRA规格、接法与固件边界
- M1为LD0832BC-0195F，Z轴LRA；额定1.8Vrms正弦、工作0.1–1.9Vrms，235±10Hz，谐振时≤90mArms，线圈21±3Ω。100g夹具≥1Grms不是成品手感保证。主体Ø8±0.1×3.25±0.1mm，另加0.3mm泡棉和0.15mm背胶。
- 它是短FPC双焊盘出线，中心到尾10.4±0.2mm、尾宽4.2mm，不是工厂导线，也不是屏幕排线。需柔性引线焊接、绝缘和应变释放，切勿拉扯尾部或挤压主体。不要把旧Ø10mm ERM安装位直接当成新LRA已合格。
- U105针序：1REG、2SCL、3SDA、4IN/TRIG接地、5EN、6VDD、7OUT+、8GND、9OUT−、10VDD。DGS封装无EP，不能误用带暴露焊盘的HVSSOP。
- REG仅接1µF对地，是芯片内部1.8V电源，禁止带外部负载。VDD输入1µF近端去耦加10µF本地储能；与MCU/I2C上拉同轨取电，避免设计成主控仍带电而驱动独立断电的状态。禁止整机断电时外部适配器继续驱动I2C。
- 驱动工作范围2–5.2V，数字VIH≥1.3V、VIL≤0.5V；实际3.192V同轨可作为候选。不得直接改接允许最高5.5V的系统5V轨。现总线：BMI270为0x69（SDO接高）、CAP1296为0x28、TCA9534为0x20、DRV2605L为0x5A，无地址冲突。保留现4.7k上拉，先100kHz实测，再决定400kHz。
- LRA直接接OUT+/OUT−，任一端都不能接地。已删除旧ERM的单管驱动、续流二极管和跨马达电容，不得自行加回。
- 额定1.8Vrms正弦峰值约2.546V；主轨最低验收3.0V时仅有理想454mV余量，实际桥损耗、采样空窗和负载影响需要测量，不能仅凭峰值小于电源便宣布输出达标。
- 额定电压/过驱钳位寄存器必须依据精确执行器和时序参数计算。TI当前RevD公式与其官方论坛承认的旧勘误存在疑点，本版**不猜写0x16/0x17十六进制配置**，更不能照搬0xFF。保存来源与验证要求，后续须使用可复核算法/厂家确认及差分波形验证后冻结配置。

### 建议固件顺序与验收
1. 上电GPIO6默认低，等待电源稳定且至少250µs；EN置高后显式DEV_RESET、等待自清、读回配置。EN低不清寄存器，也可能ACK但不能读写，不能把ACK当作初始化成功。
2. 明确选择LRA闭环及LRA效果库6；先写经过核对的额定电压、钳位和时序，再在最终固定状态下做自动校准/诊断，读取状态与结果。校准失败、过温、过流或读回不符均禁振。
3. 首次用更低幅度、短时单次效果，逐步验证至额定。只使用有限时长波形并明确结束符，不启无限循环或无期限RTP。每次请求设置最大持续时长；故障时EN拉低，主控看门狗复位也应使EN默认低。没有独立硬件超时保证，不把固件计时描述成卡死时仍可靠执行。
4. 内部4.33ms看门狗只恢复I2C协议，不会因为主控失联便自动停止振动；待机状态I2C锁死还可能需要整机断电恢复。过流/REG短路恢复可能回默认寄存器，需要重新初始化而非盲目继续播放。
5. **TI §8.3.12.4欠压例外：VDD恢复斜率低于3.6kV/s可能使状态未知，需完整断电并以快于3.6kV/s重新上电。EN切换不能保证恢复。** 首板示波器记录冷启动、低电池恢复和合法源切换斜率；先于主轨欠压禁振，无法可靠恢复就保持故障停机。
6. 差分探头跨OUT+/OUT−测实际Vrms、正负峰值、持续时长、启停/制动和温升。不要把示波器接地夹接到任一驱动输出；不能仅凭普通万用表读值批准PWM驱动电压。没有厂家明确授权时不启高压过驱；保持执行器电压在其规格内。
7. 90mArms是执行器线圈指标，不是主逻辑轨直流峰值。主轨瞬态预算可先为触觉支路预留**200mA测试余量**，它是保守工程预算而非已测最大值；与Wi-Fi、屏和其他负载并发测实际电流、压降、温升及3.0–3.3V边界，再更新预算。避免功率回流穿过IMU、MIC和触摸区，装机检查误触和IMU振动污染。

## 其他保留外围与未关闭问题
- LS1唯一扬声器：20MM-8Ω2W-JFHM / C50387209，Ø20×5.1mm。J3仅为线束接口。BTL两个端子都不能接地；启动静音、数字音量限幅与音腔/端子净空需验证。
- 电池候选为另行报告的Keeppower 400T保护18650、4Ah；本版没有改变电池接法、NTC或充电网络。**J102继续开路禁充**。现约249mA配46.4k定时电阻约6.19小时不适合直接给4Ah充满，必须先联合修订输入资格、充电电流/定时、温度和散热，不能只加大电池便开充电。
- 严禁直接焊电芯；电池线束、保护、极性、外贴绝缘NTC、安全固定均另行验证。充电禁用也不代表USB系统取电无限可用。
- 全剑灯效、Wi-Fi、声音和马达的并发预算、低电池稳定性未实测；无舵机。
- 机械外壳应采用最新FPC修订模型，不能继续用Waveshare厚模组安装位；本包不是最终可打印机械设计。

## 采购与导入
BOM中172个实体/逻辑条目，含屏DS1、马达M1、扬声器LS1共3个外壳件；其余169个是主板器件或接口候选，并非全部已定可贴装。另有8个虚拟ERC标志，不要采购。C110、C114为DNP不装。
