# 器灵 UI 与需求覆盖矩阵

UI V0.2 · 全横屏修订　PRD V1.3　日期 2026年10月16日

本矩阵区分“画面存在”“可以点到状态”“规格已写”“产品政策已确认”“真实实现或实测已通过”。页面数量不作为完成率。本轮未执行实体测试，也没有把模拟结果写成真实权益、真实记忆或实机识别。所有画面使用本轮编号，旧PRD的A01/G01等仅保留在历史正文。

本轮用户已确认全App横屏并认可当前视觉方向；App所有状态844×390，80像素左侧导航，圆屏240×240不变。认可风格不等于所有品牌/工业细节冻结。蓄势方向统一抬起/举高→就绪→向下挥斩，灯由根部渐亮至全剑身，原右斩释放仅保留为被替代的历史候选。

## 1 覆盖口径

- 静态具备：有独立SVG/PNG，可检视某个明确状态。
- 模拟路径：有热点或外侧事件按钮连接状态，结果由演示注入。它不能证明服务、传感器、计分循环或跨重启持久化已实现。
- 规格已补：UIR明确入口、动作、反馈、失败、取消、返回与验收；未单独绘制的状态仍标规格，不能因需求编号关联而算已画。
- 决策待定：K01–K03对应原D项仍需集中关闭；普通UI默认已采用，不需要逐条审。
- 实测未做：Android、IMU、联网、NFC、采音关闭、充电、人体工学、延迟与可玩性无通过结论。

R01–R24均已给出具体规则或明确验证任务。没有把其中任何一项写成“产品已实测通过”。R07/R08的完整逐次教学/玩法运行、R09远距即时非语音停局、R19人体工学、R20完整生命周期、R24关系表达验证仍有明确后续工作。其余条目也保留真实服务和硬件验证门槛。
