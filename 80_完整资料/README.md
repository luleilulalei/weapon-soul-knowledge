## 保存边界

父目录原资料未修改。这里排除知识库自身，防止递归复制；不收录 `.DS_Store`、AppleDouble 等系统元数据或原目录的 `.git` 内部数据库。排除项逐项记录在清单里。一个原有空目录也已记录；Git 不直接保存空目录。

原生 CAD、STL、SCAD、Gerber、APK、Mac 应用及压缩包均已保存。推送 GitHub 时，997 个原文件使用普通 Git；超过100MiB的 `UnityPlayer.dylib` 使用 Git LFS，Git记录校验指针，完整原文件保存在同一仓库的LFS存储中。克隆后执行 `git lfs pull` 可恢复完整内容；[存储方式清单](../90_来源/Git存储方式.json)记录该文件的路径、大小与SHA-256。

归档表示文件完整保存，不表示旧版本重新获得批准、历史测试重新执行，或原开发环境可以在任意电脑上直接运行。
