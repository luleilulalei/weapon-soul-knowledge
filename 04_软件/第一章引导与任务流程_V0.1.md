# 第一章引导与任务流程

版本：V0.1设计草案 · 2026-10-25

依据：[第一章创作要求](<../90_来源/文档快照/S122_第一章从激活到完整剧情的创作要求_20261025.txt>)；既有[RPG与故事方向](<../90_来源/文档快照/S115_协作RPG副手控制与狂暴器灵故事方向_20261024.txt>)。

配套剧情：[第一章《最后一盏归灯》](../02_角色与世界/第一章_最后一盏归灯_V0.1.md)。本稿将用户要求的“拿到器灵—激活—引导—完整第一章”拆成可制作、可试玩的步骤。角色、任务、时长和操作判定均为方案，尚无本章实现或真机验证结论。

## 首次体验原则

实体器灵承担伙伴的声音与反馈，App承担账号、状态、游戏场景、字幕和必要输入，不增加App AI聊天。初次开机短台词采用固定演出即可；角色自报姓名与现实设备的身份验证分别处理。发现设备、建立连接、确认账号归属是不同步骤，不能仅凭名称或连接成功就判定为本人所有。

用户不开麦，也能通过操作完成全部主线；开启语音遵循明确许可。普通唤醒不打开已关闭的麦克风。圆屏只显示表情与状态，不出现“点击器灵屏幕”的指引。首次体验中的开机时机、语音、灯效、震动均需固件联调，不宣称已实现。

玩家只需一种战斗形态。以下同时写光剑和法杖映射，用来保持剧情兼容；首个制作形态仍待选择，不要求首版同时完成两套动作识别。副手控制器按移动、交互、暂停等功能描述，具体按钮和通信未冻结。

## 按故事逐步解锁操作

| 步骤 | 玩家正在经历什么 | 本步要求与通过条件 | 提示与失败处理 |
|---|---|---|---|
| CH1-00 开箱与开机 | 沉睡内核第一次发出声音 | 关机安装当前组件，再开机；看到本机响应 | 保留文字开机指引，不依赖语音输入；无响应按设备故障处理，不算剧情失败 |
| CH1-01 连接与归属 | 确认即将同行的伙伴 | App完成必要账号流程、连接及归属验证，用户能核对手中设备 | 被他人绑定或网络异常时显示真实状态，不能播放“绑定成功”；允许退出稍后再办 |
| CH1-02 正式认识 | 伙伴报出原名，了解新搭档 | 展示砺光或绒芽的自我介绍；称呼可填写或跳过 | 不做性格问卷；名字不代替认证，跳过不阻塞主线 |
| CH1-03 后院磨合 | 出发前试着一起行动 | 放稳手机、取下副手；走到院门、转向工具台、停止；中位校准；暂停后主动继续一次 | 一次只显示一个目标；不要求现实走路，不要求点击实体圆屏；只重试未完成项 |
| CH1-04 攻击练习 | 试用练习靶 | 光剑按提示完成两种方向挥砍，或法杖完成一个简单攻击符 | 成功先给命中反馈，再增加要求；只判动作类别与时机，不比谁挥得更猛 |
| CH1-05 防御练习 | 接住慢速脉冲 | 光剑方向格挡或法杖护盾符；完成两组移动、攻击、防御组合 | 首发放慢，随后减少提示；失败仅重置当前组，可自选继续练习 |
| CH1-06 第一单救援 | 接单进入渡口外围 | 主动接单；停用巡检机、首次拾取、打开背包、找到阿禾并开路 | 提示沿用已学图示；先单敌再组合；败退回本段入口，不重播首次设置 |
| CH1-07 初见镇岳 | 听见它仍在问船是否过去 | 看到守闸行为，完成一次明确提示的防御，退回安全点 | 作为短遭遇，不以打空Boss进度为目标；失败重试这次防御，保留救援结果 |
| CH1-08 三处调查 | 查明约定、行动与结果 | 取得维修棚信号约定、控制室守闸记录、灯台撤离结果三条证据；收齐必需材料 | 一次短战斗穿插调查；可重读证据，必需材料不要求额外组件或购买 |
| CH1-09 暂歇与计划 | 阿禾拿出工具包，准备把话带回去 | 明确“护送修灯—稳定闸门—让双方交流”的计划；玩家主动开始 | 显示自然休息点，可退出；不以NPC催促阻止休息 |
| CH1-10A 打开通路 | 解除镇岳外层失控构件 | 应对横扫、地面冲击；攻击收势窗口，解除两处过载节点 | 新组合首次给提示；失败从本阶段安全开场重来，不清空已得线索 |
| CH1-10B 保护检修 | 阿禾修复灯线与渡铃 | 清理巡检机、挡住冲击、操作虚拟支撑点，推进分段修理 | 修理段落完成后记录；失败从当前段重新布置敌人与位置，避免带着残留危险恢复 |
| CH1-10C 接过守护 | 为最后的修复争取时间 | 完成有间隔的三次防御，三声渡铃后归灯转绿 | 不持续高举双臂；失误重试本小段，允许暂停、重校准并选择教学辅助 |
| CH1-11 接它回去 | 阿禾回答老周的结局 | 听完关键对话；玩家操作虚拟支撑，让阿禾取下内核 | 无敌人攻击；可看字幕、重读或跳过已看演出，不靠声音识别做任务门槛 |
| CH1-12 第一次收工 | 清晨归来，伙伴有了共同经历 | 确认任务结算，展示实际到账内容；结束本次游玩或主动进入练习 | 待确认奖励不显示已到账；收纳副手不假定具有自动检测能力 |

校准只能建立器灵的相对中位，动作映射需真实IMU验证。文中的命中、扶稳支撑、解除节点都是游戏中的动作或交互，不要求追踪现实剑尖绝对坐标、触碰实物目标或接触另一位玩家。

## 单一形态也能完整体验

| 任务功能 | 光剑路线 | 法杖路线 |
|---|---|---|
| 常规输出 | 按提示方向挥砍 | 简单攻击符 |
| 防御脉冲 | 提示方向格挡 | 护盾符，成功后在有限窗口抵挡 |
| 清理过载节点 | 在窗口期攻击可达节点 | 在窗口期施法命中节点 |
| 操作支撑与取出内核 | 对准游戏目标后确认交互 | 同左 |
| 主线修理材料 | 拾取维修箱、回收巡检机材料 | 同左 |

目标选择方式、格挡有效窗口、符咒起止判定和辅助等级需原型验证；剧情不强制新增瞄准传感器。斧头砍木、锤子采矿可以后续加入同地区的可选资源任务。Boss镇岳是锤形NPC，不意味着玩家必须购买锤组件。

若切换实体组件，必须先在安全点退出战斗并关机，重新安装后再连接、核对形态和校准；不安排战斗中热插拔。此行为不改变伙伴身份。

## 三段游玩与恢复

首次全章暂按40—55分钟预算：相识与练习约10—14分钟，救援与调查约15—20分钟，守闸、告别与收工约15—21分钟。数字不含连接等待，也不是试玩结论。每段结束可自然停下，段内同样允许暂停。

最少保存：已完成引导、当前任务段、三条证据、修理材料、当前安全检查点和结算状态。恢复只回到清楚的安全开场，不重放开箱绑定，不把中断前尚未确认的挥动当作新攻击。故事不会在退出期间自动恶化。

| 中断 | 必要行为 |
|---|---|
| 主器灵或副手失联 | 立即停止角色连续移动和战斗输入，暂停任务；重连核对后由玩家明确继续 |
| 手机切后台、主动暂停 | 停止推进，不积累后台攻击；回到前台先显示暂停状态 |
| 进入充电 | 禁止体感战斗，保存到安全恢复点；可继续正常陪伴，停止充电也不自动续战 |
| 放回收纳位置 | 没有检测信号时依靠明确结束操作；不能把副手扣回或USB供电推断为已经入座 |
| 可识别的正式入座事件 | 沿用项目规则，结束旧局；离座不恢复旧局，后续由用户主动从已保存任务点开始 |
| 关麦或无法语音 | 停止采音；用App操作与字幕继续，无须重新开麦通关 |
| Boss失败 | 回到当前阶段的安全开场，可选择重试、练习或退出；保留已完成调查 |

正式任务进度与奖励以服务端确认结果为准，重复上报不重复发奖；失败待确认时保留待结算状态。若提供离线训练，需清楚标明练习身份，沿用“不产生长期成长”，不能借离线重复刷取正式奖励。具体后端实现尚未完成。

结算记录剧情事实与合法资产，不等于新增私人记忆采集许可；不出现“是否保留这次记忆”的结算弹窗。现有记忆只读、可删除等规则继续适用。

## 剧情需要被玩家理解的四件事

1. 老周和镇岳守住闸机，让最后一船人得以撤离。
2. “绿灯、三声铃”原本意味着船已安全抵达，但洪水切断信号。
3. 人们成功到岸，老周却死于之后的坍塌；镇岳没有收到完整结果。
4. 玩家压制现场危险、接过守护，阿禾修复信号并亲口告知真相，镇岳才愿意离开。

不能只放一页文字解释这四点：先听镇岳的重复问话，再拿到分散证据，最后在玩家完成防御时实际呈现绿灯与三声铃。阿禾从当事人、技术协作者到说出真相的人都有明确作用。

## 首个制作版本与试玩验收

建议先制作一个后院/安全点、可复用的沿河路与三处调查点、一个旧闸战场；一个普通敌人配置两种攻击、一个三阶段Boss、阿禾的固定协同行动。主线文字、现场记录和少量关键演出优先，避免先铺大地图。该资产预算是制作提案，不是冻结范围。

首版可先接通一种战斗形态和一位伙伴，另一位复用任务结构、替换观察与台词。NPC协助可验证保护目标与分工，但不作为多人联机已完成的证据；长期协作RPG方向保持。

试玩需要回答：

- 新用户是否能在不开麦的情况下认识伙伴，完成移动、攻击、防御与暂停？哪里需要人现场解释？
- 中途退出、断连或失败后，能否从合理位置继续，且没有角色失控移动、旧动作补发或重复发奖？
- 看完后能否说清“船是否成功撤离、老周为何没回来、镇岳为何不走、玩家为何需要阿禾”？
- 关键防御是否让人感到参与了救援？重复动作是否有运动投入感，休息点是否够用？
- 第一章完成后，训练回放是否明确区别于正式故事，镇岳与阿禾的生活是否保持已经改变的状态？

本轮交付为剧情和流程文档；上述项目需后续工程与真实设备试玩验证。
