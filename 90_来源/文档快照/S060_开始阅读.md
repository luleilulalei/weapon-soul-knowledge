# 器灵 单 IMU 第一版

2026年10月17日。本包是单 IMU 玩法的实现规格、Unity 功能原型源码和验证材料，不是已构建的 App 或已接硬件的成品。

## 先看什么
1. spec/器灵_单IMU_MVP实现与验收规格.docx：玩法边界、动作、异常恢复、验收与本轮实现差异。
2. unity/README_运行与边界.md：在新建空白 Unity 测试项目中导入源码、模拟操作和 CSV 回放的方法。
3. validation/独立审查与验收边界.md：实际做过的检查与尚未执行的检查。
4. spec/实测记录模板.csv：后续真实样机采集记录；不是已有实测数据。

## 包含什么
- 左右斩、下劈、姿态格挡、朝上蓄力、取消与归位的规则及候选输入处理。
- 动作教学、节奏挑战、Boss攻防的功能原型 C# 源码。
- 明确标记的模拟动作注入、人工合成 CSV 回放和真实输入适配接口。
- 确定性状态机测试源码、Python 参考验收和本轮规格。

## 必须保留的边界
- 本环境已运行的是 Python 参考测试和合成数据检查；未执行 C# 编译、Unity 编辑器运行、Android 构建或实体 IMU 验证。
- 合成回放与按钮操作不能证明真实动作识别准确率。原始识别器为待标定的简化候选算法。
- Unity 源码只导入新建空白测试项目。界面是功能验证界面，不替代此前已认可的高保真全横屏 UI。
- 不含 BLE 传输、设备固件、实物灯声震驱动、真实账号、成长发奖或联网结算。
- 圆屏仍是非触摸显示；手机模拟按钮不是光剑圆屏交互。
- 朝上姿态不等于举过头顶，动作类别不等于真实三维剑尖轨迹，动作强度不等于击打力。
- 本包没有修改已交付原理图；器件匹配、封装冻结和制造条件仍按硬件评审处理。
