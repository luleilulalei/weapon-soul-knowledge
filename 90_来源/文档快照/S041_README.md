# 器灵 · Unity 训练场开发版

依据《器灵_UI与PRD修订源包_V1.4》的 game/screens.md、context.json 与 PRD 修订实现。原设计包未修改。

## 打开与运行

1. 使用 Unity Hub 打开本目录，编辑器版本 **2022.3.62f3c1 LTS（Intel Mac）**。
2. 首次导入后会自动生成 `Assets/Scenes/Training.unity` 并设置横屏；也可点击菜单 **器灵 → 准备工程**。
3. 打开 Training 场景，点击编辑器顶部 Play。界面和游戏控制器在运行时生成。
4. 首次从辨向开始，完成后开放节拍，再完成节拍开放守门者与蓄势斩。进度只在本次运行内存在。
5. 菜单 **器灵 → 运行核心规则测试** 执行自动断言；**构建 Mac 开发版** 输出 `Builds/Qiling Training.app`。
6. Android 构建工具已安装；菜单 **构建 Android 开发版** 输出同时包含 ARM64 / ARMv7 的 APK，最低 Android 8.0。

## 开发模拟输入

| 输入 | 动作 |
|---|---|
| A / 左方向键 | 左斩（你的右 → 左） |
| D / 右方向键 | 右斩（你的左 → 右） |
| 按住空格 | 格挡姿态；松开结束 |
| 按住 W | 举剑蓄势；就绪后松开，再下斩；提前松开会取消 |
| S / 下方向键 | 向下释放 |
| U | 无法识别的动作 |
| X | 离开姿态 |
| Esc | 普通暂停 |
| F1 | 开发模拟面板，可用鼠标或触屏注入事件 |
| C / L / B | 切换充电 / 连接 / 入座 |

这些输入仅用于编辑器和 Development Build，不是实体按键映射。正式非开发构建默认不开放模拟且设备状态不通过；接入可信硬件前不能开始训练。

## 本轮实现

- 八套共享界面：大厅、准备、教学、HUD、暂停、恢复、结果核对、结算。
- 辨向六次提示、至少四次有效；节拍四组、至少三组完整；守门者双方三格生命。
- 基础斩、左→右回锋、举剑蓄势→向下释放三条反击路径。
- 空间与手机放置确认、8 秒站位、示范、不计分验证、3 秒开局。
- 新鲜设备状态门禁；充电、入座、断连、风险和后台中断处理。
- 动作 ID 去重、窗口匹配、输入时间校验；未知动作不补为成功。
- 暂停保留已确认计数与生命，清空未完成组合/蓄势；恢复重新验证。
- 唯一终态；重连和终态核对分离；结算按真实计数计算。
- 中文字体、横屏等比布局与安全区域适配，训练中显示实时 3D 场地。
- 游戏不提供聊天、手机录音、记忆编辑或结算记忆保留选项，也没有自动写入长期记忆。

## 代码入口

- `Assets/Scripts/Core/TrainingSession.cs`：不依赖 Unity 的状态机和规则。
- `Assets/Scripts/Runtime/TrainingGame.cs`：Unity uGUI 界面、键盘模拟及输入适配接口。
- `Assets/Editor/CoreTests.cs`：对生产状态机执行的自动检查，可在 Unity 或独立 C# 编译器中运行。
- `Assets/Editor/ProjectSetup.cs`：场景初始化、横屏配置及测试/构建菜单。

## 硬件接口约定

通过 `TrainingGame.AttachHardware(ITrainingInput)` 替换模拟输入。适配器必须在 Unity 主线程调用；后台 BLE 回调应先入线程安全队列，再由 Poll 消费。

- `DeviceStatus` 默认不信任任何硬件状态，2 秒未更新即阻断。当前 2 秒是开发参数，不是已批准安全阈值。
- 动作包含全局单调事件 ID、当前判定窗口号、转为本机单调时钟后的采集时间。
- 校验旧窗口、重复事件、超过 0.5 秒的旧输入以及明显未来时间。
- 蓄力需真实硬件持续提供状态和离姿/中断事件；目前键盘模拟保持姿态不代表实机识别。
- `ResolveInterrupted(sessionId)` 只用于已核实中断的结果；不得因连接恢复自动调用。
- 目前只有本地中断模拟，没有网络权威结算或重启恢复账本，不应投入正式联网训练。

## 明确未完成

这是实时 3D 开发样机，场地和可活动敌人为程序生成简模。正式角色美术、音效、实体灯声震、蓝牙协议、原始 IMU 融合和识别、账号授权、后端结算、长期成长持久化和 Android 真机验证尚未完成。完整 App 功能也尚未全部接入。

## 3D 轨迹输入

点击左斩、右斩、下斩会播放连续剑轨迹；也可在画面中央拖动。轨迹经过方向识别后交给规则层，并非点击直接扣血。按住格挡或蓄势按钮保持姿态，蓄势就绪后松开，再下斩；提前松开会取消。键盘空格和 W 同样需要按住。

`SwordTrajectory` 负责轨迹与方向识别，`Arena3D` 显示敌人、剑光拖尾和命中效果。通过 `AttachHardware` 禁用模拟后，`Trajectory.PushHardwarePose` 接收已融合、校准和时钟同步的姿态四元数；动作事件仍由硬件适配器提供。当前固定握持点和剑长用于显示，不能当作真实空间位置测量。此接口不是已完成的 BLE 或原始 IMU 算法。

已通过 158 项规则/轨迹断言，以及真实播放器内连续斩击、格挡、持续蓄势与下斩命中的集成检查。日志：`TestResults/3d-player.log`；画面：`TestResults/3DScreenshots`。

本地练习开放技能只用于检验流程，退出运行即清空，不产生长期成长。动作窗口与蓄势时长均为可调整开发默认值。触屏暂停与键盘模拟不能证明“关麦下远距即时暂停”已解决，仍需硬件控制方案与实测。
