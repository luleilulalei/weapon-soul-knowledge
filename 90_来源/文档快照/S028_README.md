# 器灵非触摸圆屏 V1.4 R2

2026-10-18。基于已交付非触摸圆屏 R1 建立的新版本副本，旧目录未修改。先看 boards/01_圆屏与输入物理分离.png；完整状态见「器灵_非触摸圆屏完整状态板.pdf」。index.html 为可本地打开的画外评审模拟器，须保留 screens 子目录。

## 本次范围

- 既有记忆允许查看与删除，不允许更正、编辑、改写或覆盖保存。
- D25 由更正确认改为查阅目标定位；M02 由修改完成改为只读查阅。原编号只用于追踪，不恢复旧语义。
- D21—D24/M01 只用于硬件对话中的新记忆许可、保存及结果核对；不用于闯关保留/舍弃记忆，不改变已有记忆。
- 闯关不出现记忆保留询问、保留/舍弃选择或开关。此处不决定闯关记忆是否自动生成、保存或保留。
- 器灵对话仅在硬件侧。游戏 App 不提供器灵聊天入口、对话输入或发送操作；App 的记忆查看、删除与确认不等于对话功能。
- D26—D28/M03 的删除对象、影响、明确确认、处理中及真实结果保留。采音隐私、权限与未知结果处理继续有效。
- 圆屏只显示，无触摸事件、无手表式菜单。实体按键和独立触摸区的具体输入方案仍待批准与验证。
