器灵交互补图与 PRD 承接

UI V0.2 · 全横屏有限补图　承接 PRD V1.3　2026年10月16日

本文件仅补齐核心横屏包中尚为说明级的授权手机、退出与诊断、四类动作教学、实体菜单画面。核心包及其74条UIR、13份模块PRD已冻结，本补图不修改它们，也不另建重复需求体系。普通App页面继续844×390横屏与80像素侧栏，游戏教学保持横屏，实体圆屏240×240。新增编号使用X-A / X-G / X-D，不能与核心A/G/D编号混用。

1 先看本批做了什么

1. 把“授权手机与退出”补成可看见对象、影响、提交中、部分生效及完成的流程，旧端离线仍如实提示。

2. 把基础斩、格挡、回锋、蓄势分别补成示范、站位准备、尝试、纠正、未知输入、通过与重试的教学。

3. 把实体复用键候选A补成具体菜单及确认画面，保持关麦事实、取消和真实关机完成的区别。

4. 修复、纪念、转赠只作影响预览；本批不提供真实转赠、注销、迁移、售后或新社交功能。

这是有限的图和交互补充，不扩大MVP政策范围。画面、按钮和自动示范均使用虚构状态，不证明真实权限撤销、传感器识别、远端清理或电源安全。

3 App 设置、授权与生命周期预览

承接UIR-002–007、008、065–068；原ACC-008/009/013–016、D05/D06/D10；主要补审计R20，也涉及R17/R23。

3.1 授权手机：撤销请求、服务端访问与旧端清理分层

列表按当前有效账号和明确器灵范围显示手机标签、可区分尾号、是否本机、最后确认时间与同步状态。名字、型号或“在线”不等于主人证明；不要暴露另一账号的列表。

选中旧手机后，确认页固定该授权对象与影响范围。撤销访问不等于解绑器灵、删除共同经历、撤回合法技能、注销账号，也不能承诺删除用户已另行导出的内容。

提交前取消不变化；提交后按钮锁定并显示处理中，返回只离开页面，不取消已提交的撤销。同一请求可重入查询，未知结果只核对原请求；只有明确未受理才可重新提交。

推荐服务确认失效后阻止旧授权继续访问在线资源。旧端离线、本地会话尚未结束或清理回执未到时，分别显示已确认范围与“旧端待同步”，不能写“所有设备已立即退出/已全部清空”。这一传播与本地清理政策仍属K02。

当前端显示“已完成”的必要条件是本产品已批准范围全部获得完成证据；若只收到服务端失效回执，只能写该事实。离线端后来同步应先执行失权遮蔽/获批清理，再提供重新登录，不先恢复旧私人详情。

权限在查看/提交/回调时失效，立即遮蔽未获准详情；在途请求仍按原对象核对，不能转为新登录用户的操作。异步结果不得在切换器灵后改另一个对象。

3.2 退出账号：结束本机访问，不伪装全量删除

退出确认列清本机私人可见内容和会话的处理；已提交未核对的卡牌/记忆/授权请求仍归原账号，不靠本机退出撤回。

未提交编辑可取消退出并继续；确认退出后立即遮蔽私人内容、清除本机可访问会话，并按获批策略处理缓存。离线时能够本地退出就先完成本地动作，远端会话注销未确认须单列，不能假报全端生效。

本机访问已锁定但清理尚未完成使用X-A06P；遮蔽私人内容，保留核对/重试本机清理，不回到可访问个人设置，也不先标已清除。

完成态返回登录准备/退出后的安全入口，侧栏不能绕回已登录示例。再次进入需正常验证，不能以旧页面缓存恢复权限。

退出、本机缓存清理、撤销旧手机、解绑、删记忆、转赠和注销是不同操作，不使用一个“重置全部”按钮。

3.3 三连接诊断和声音显示

手机↔器灵、器灵AI网络、App网络分别显示当前、未知、上次确认。刷新只读取事实，不自动开麦、改主人、重发消费或恢复旧战斗。

诊断失败给对应层的下一步，不建议为网络故障解除隐私；旧麦克风状态只能标上次确认，不能继续显示为当前安全事实。

声音/显示仅调整明确的本机App呈现范围。音效静音不等于实体停止采音；减少动效不取消必要状态；不假设额外环境传感器或未实现的实体自动亮度。

演示开关可改变本演示界面，不能暗示已写入实体；有实体设置时须另标目标、提交中与设备回执，本批不据此增加新控制接口。

3.4 修复、纪念、转赠只读预览

修复预览明确“原整机身份核实后可延续”，不以名字相同或备份写入另一整机证明是原器灵。证据不足保持待核实。

纪念预览说明只读或获准的纪念能力，不开放新实体训练、继续自然成长或复制权益；不自动把当前正常器灵切成纪念。

转赠分别说明卡牌特性、私人记忆、自然成长、账号资料及必要消费记录。卡牌特性随原器灵的已确认方向保留；私人记忆和一般成长Q43仍未决定。

这些页面只有查看、返回与清楚的未开放说明；不存在执行交易、转赠、注销、永久删除或迁移的成功路径。若画“联系支持”，未实现渠道不得伪装已提交申请。

4 四类动作教学的完整节奏

承接UIR-008、024、046–057、059、068–070、073；原CB-001/002/006/007/014/016、GM-002、D04/D07/D09；主要补R07/R10/R11/R13。

4.1 共用安全和教学状态

X-G01选择学习单元并说明当前为教学。未拥有蓄势斩可在受控教学临时试用，但正式收藏、解锁条件和战斗资产不变。

X-G02先留近屏操作与回站位时间，再复核实体输入、形态、充电与安全状态。画面的8秒属于演示值，不是冻结安全阈值。倒计时结束不绕过设备检查；没有有效状态不开始尝试。

每单元均按示范→起始姿态/当前提示→尝试→具体反馈→重试/通过推进。示范自动播放只是教学提示；尝试只能由明确模拟事件或未来真实输入推进，不能因示范动画结束判玩家完成。

近屏点继续、重试或恢复之后，先回站位准备，避免按钮一按就开放攻击/计分窗口。玩家可停止动作、放下剑后操作；不为了保住进度要求危险地抢按。

旧输入、计时器和回调绑定教学单元、轮次及阶段。重试、切课程、暂停、断连或退出后旧事件失效，不接续半个组合或旧蓄力。

4.3 纠正、未知、通过与离开

X-G11只反馈当前确有证据的一项原因，给下一次怎么做，不羞辱或诱导加力。纠正后按选中单元重新示范；不默默跳过没学会的一段。

X-G12用于没有足够可用输入，不能改写为“方向错”。提供重新准备或回看，输入一直无效则退出到诊断/安全入口，不在无限尝试中持续要求挥动。

X-G13只表示本次教学步骤完成，允许继续下一单元或离开。本批完成记录只保存在本次访问内存，退出清空；不永久解锁技能、不发战斗成长，也不自动保存长期共同经历。未来如保留练习历史，须明确来源并另按原政策实施。

X-G14区分普通暂停与异常中断原因。普通暂停恢复先回X-G01安全准备，再经X-G02回站位并重新进入安全示范/尝试阶段；断连、入座、充电、风险按核心规则结束或限制，不借“教学”绕过安全门禁。

退出、异常结束、切换到正式挑战时清除教学试用与临时动作。若真实技能原本已拥有则仍保留；未拥有者不能通过返回键或重开教学变成永久拥有。

5 实体菜单候选A的可见细节

承接UIR-006/007、019、025、027–030、057、073；原Q107/Q135、D05/D07/D-HW03；主要补R16/R17，R09远距停局仍不因此关闭。

普通陪伴短按取消本轮/查看当前状态；正在处理或说话时使旧输出失效；浅/深眠单按唤醒但保持原采音状态。双击只关麦，不是开关切换。

独立长按打开控制菜单，初始选中“返回”。短按循环项目；先释放，再用下一次独立长按确认。开菜单或循环到某项本身不能执行该项。

显示当前选项、真实采音事实及简短操作提示；菜单不靠眼神替代开麦/关麦事实。超时或取消回原可用状态，不默认执行关机或开麦。

开麦选项先满足当前有效权限和明确非语音确认，提交后等实际采音状态；成功才标已开启。权限未知、失败、结果未知各自提示，不把没有回执当成功。普通唤醒、返回菜单或取消都不恢复关麦。

休眠和关机分别处理。关机菜单确认只表示请求被确认，之后仍为关机中；只有真实安全关断边界及可用反馈条件满足，才可短暂给完成提示并熄屏。屏幕黑了、动画播放完或按钮松开都不能单独证明允许拆装。

同一次持续按压不得同时“唤醒→开菜单→确认”；进入关机后不把残留按压当重开机。双击/长按临界、按键抖动、手持误触、确认超时由实机消歧，不在图稿冻结毫秒值。

战斗或离线练习短按停局仍为K03候选；没有真实停局确认不能显示已暂停。菜单补图不是远距即时停局已解决的证据，也不允许在安全中断时继续邀请挥剑。
