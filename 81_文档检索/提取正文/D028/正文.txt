第3页：11_Charger
SPIRIT / 11_Charger / 原理图复核版 2026-10-18
CE through R108 low = charge enabled. EN2=USB_HIGH_CURRENT_OK; EN1 is its inverted signal pulled to VSYS_RAW. BQ24075 retains USB/battery power path.
R111=1k sets nominal 890mA charging; real charge current is reduced by input limit, system demand, DPPM and temperature. It is not an extra load allowance.
R110=1.18k acts in ILIM mode only. CC default/unpowered -> EN1=1 EN2=0 USB500; Rp1.5A/3A -> EN1=0 EN2=1 ILIM. Main off -> USB500 fallback.
样机条件：使用4.2V充满的单节保护电池及贴附电芯的10k NTC；电流和温升待验证。
R111=1k，充电标称890mA；R112=69.8k，安全计时典型9.31h；DPPM优先供系统。
Type-C Rp detection is hardware implemented in USB page. No PD negotiation or USB enumeration/suspend-controlled 100mA mode. Validate intended sources and full-load thermal behavior.

第4页：12_Main_switch
12_POWER_BUTTON / 长按电源键；取消 J111 双刀机械开关
开机：SW4 长按约 2.2 秒；关机：长按约 3.2 秒后通知主控保存，随后关闭供电。
U110 由 VSYS_RAW 常供电；EN 控制 TPS63802。R116 保留为 BUCK_EN 上拉。
MAIN_IN 并入 VSYS_RAW；BOOST_5V 并入 +5V_SYS。BQ24075 充电路径不变。
关机时 3V3 下降，BOOST_ENABLE 经 R120 下拉，TPS61023 进入输出断开状态。
GPIO14=PWR_INT_N；GPIO6=PWR_KILL_N，仅使用输入高阻或开漏；GPIO44/43 保留 UART0 RX/TX。
R141 从 3V3 上拉 KILL，启动无需固件在 512ms 内接管；复位和 USB 下载不会主动关电。
INT 有效后固件应在 700ms 内关闭负载并保存，再拉低 KILL；硬件约 0.8~1.3s 强制关闭。
关机保留充电和按键检测。BOOT / RESET 留板上调试，外壳仅露 POWER。
时序含电容/控制器误差；USB 插拔、低电池、故障关机、残压与实物待测。
