# 产品定位与范围

器灵是实体角色、体感游戏和长期陪伴构成的互动产品。用户反复强调：玩具本身要好玩，单靠对话不足以让人愿意持续投入；人格、造型与交互要共同服务“器灵太好玩了”。来源：[历史聊天摘录](<../90_来源/聊天摘录/6acdd980-0af8-83ea-8e58-51a017d4eab5.md>)、[历史聊天摘录](<../90_来源/聊天摘录/6acdebd7-1b48-83ea-b474-e591ba5fa89a.md>)。

## 明确的产品方向

- 采用“通用器灵内核 + J7外接形态组件”的产品架构。原“剑柄”主体改称“器灵内核”，通过不同组件形成光剑、法杖、锤子、斧头等形态。光剑与法棒/魔杖的既有方向保留为形态分支，首发组合待定。[器灵内核方向确认](<../90_来源/文档快照/S114_器灵内核与J7模块化形态_20261024.txt>)
- 法棒用空中绘符触发攻击与防御；光剑以方向、格挡、组合和蓄势形成战斗。锤子与斧头的具体玩法尚未定义。
- 情感培养和体感游戏并重。首发希望采用有剧情的关卡，包含怪物、战利品和Boss。
- 角色有固定核心人格、自己的经历与判断；与玩家共同完成使命，不只是被动应答。
- 整体面向全年龄的长期方向保留，当前先做成年样机验证，正式最低年龄尚未冻结。成熟角色设定不自动改变适用年龄。

来源：[V1.5总纲](<../90_来源/文档快照/S045_00_阅读入口与产品总纲.md>)、[角色设定](<../90_来源/文档快照/S092_器灵角色设定_绒芽与砺光_V1.0.md>)、[总PRD](<../90_来源/文档快照/S063_00_产品总PRD.md>)。

## 器灵内核与模块化形态（2026-10-24）

器灵内核是不同形态共用的实体功能主体。复用目标从PCB扩大到内核及可共用的结构、外壳部分，开发不同形态时主要设计相应的外接组件。J7作为内核与形态组件之间的电气连接接口；配套机械连接需要另行明确。

| 组合 | 产品形态 |
|---|---|
| 器灵内核 + 光剑组件 | 光剑 |
| 器灵内核 + 法杖组件 | 法杖 |
| 器灵内核 + 锤子组件 | 锤子 |
| 器灵内核 + 斧头组件 | 斧头 |

减少重复开模投入是本次调整的动机；专用外接组件仍可能需要各自的模具，实际节省须按结构方案和报价核算。内核的具体共用边界、接口定位与承力、组件识别及形态切换仍待设计。本决定未更改既有身份、人格与记忆规则，也不等于四种形态同时首发或已经完成工程验证。

来源：[器灵内核方向确认](<../90_来源/文档快照/S114_器灵内核与J7模块化形态_20261024.txt>)（用户方向已确认；实现细节未冻结）。

## MVP与未来内容

当前工程以单人、单实体、Android、固定站位体感为基础；整个App用Unity。首版不包含双实体互相对话、联动或合击；这不等于已经取消玩家社交的所有可能形式。iOS、多人、更多剑身尺寸和跨设备深度玩法需另定版本。

完整App、联网权限、实体灯声震、卡牌兑换、语音和长期成长是需要串起来的产品系统。现有训练场只覆盖其中一段；其测试数不能证明产品闭环已全部成立。

一位玩家当前使用一把器灵；每台实体保有自己的身份与资产。V1.5建议任意一款能独立完成主线与结局，具体内容规模和发售组合仍待评审。

## 需要继续作出的范围决定

通用器灵内核方向已确认；内核的共用结构范围、不同形态的适配细节、首发组合、NFC使用方式、十二关内容预算、玩家社交最小范围、正式适龄与商品组合仍待明确。不要用工程方便替用户取消绘符、改触屏或删掉独立身份。
