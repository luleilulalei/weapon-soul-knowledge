# 交互与身份规则

以下是跨硬件、App、游戏和AI共同遵守的规则；它们描述产品行为，未全部完成实机验证。

| 场景 | 当前规则 | 来源 |
|---|---|---|
| 对话 | 仅实体麦克风输入、实体扬声器输出；App无聊天/手机代发入口 | [V1.4修订](<../90_来源/文档快照/S036_01_记忆与对话端分工_决策补充.md>) |
| 屏幕 | 圆屏显示眼睛、状态和简短反馈；不做屏内触控菜单 | [非触屏修订](<../90_来源/文档快照/S029_器灵_非触摸显示屏_补充修订.md>) |
| 触摸 | 保留壳体多区域独立电容触摸，区别于屏幕触控 | [机械旧基线](<../90_来源/文档快照/S090_CURRENT_BASELINE_当前设计约束.md>) |
| 充电 | 正常充电可完整联网陪伴，禁止体感战斗 | [硬件PRD](<../90_来源/文档快照/S064_01_实体光剑硬件.md>)、[机械旧基线](<../90_来源/文档快照/S090_CURRENT_BASELINE_当前设计约束.md>) |
| 入座 | 结束旧游戏，按主动退出处理；不能只暂停等待离座恢复 | [身份规则](<../90_来源/文档快照/S071_08_账号与系统协作.md>) |
| 离座 | 根据当前剑身和实际充电状态回到可用模式，不恢复旧攻击 | [身份规则](<../90_来源/文档快照/S071_08_账号与系统协作.md>) |
| 关麦 | 停止语音采集，IMU和非语音退出仍可工作；普通唤醒不恢复采音 | [麦克风变更](<../90_来源/文档快照/S016_麦克风需求变更_20261020.txt>)、[单IMU规格](<../90_来源/文档快照/S053_器灵_单IMU_MVP实现与验收规格.md>) |
| 配件拆装 | 断电插拔；DET是识别信号，不是硬件切电 | [配件接口](<../90_来源/文档快照/S015_配件接口定义_20261020.txt>) |
| 离线训练 | 不产生长期成长，不在重连后补算为正式奖励 | [总PRD](<../90_来源/文档快照/S063_00_产品总PRD.md>) |
| 身份 | 一机一器灵；同名不合并；更换手机不复制实体身份 | [身份规则](<../90_来源/文档快照/S071_08_账号与系统协作.md>) |
| 权限 | 唤醒、连接成功、持有卡片均不等于主人认证 | [身份规则](<../90_来源/文档快照/S071_08_账号与系统协作.md>) |
| 记忆 | 查看与删除，禁止用户改写；删除不撤销合法游戏资产 | [V1.4修订](<../90_来源/文档快照/S036_01_记忆与对话端分工_决策补充.md>) |

账号、实体身份、当前连接设备和本次操作目标要分开。NFC兑换、设置和结算都明确目标器灵；切换查看页面不能改变此前操作的归属。

更换手机与原机维修不等于跨整机迁移；官方恢复身份需要原整机身份连续性依据。转赠的已兑换特性已有携带方向，私人记忆和成长如何处置仍待决定。

“已收到动作”“判定命中”“完成结算”“设备已表现效果”是不同事实。断连、重试、恢复时核对原操作，未知结果保持待核对，不伪造成功。远距关麦停局、故障关麦与跨重启保持仍需实现与实测。
